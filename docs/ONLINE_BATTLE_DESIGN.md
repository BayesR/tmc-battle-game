# オンライン対戦（フレンド対戦）設計メモ

最終更新：フェーズ0（下準備）完了時点。実装済みの範囲と、これから作る範囲を分けて記載する。

## 基本方針

1. **サーバーが「正」の状態を持つ**：判定はサーバーだけが行う。クライアントは「カードを選ぶ」「次へ」などの意思表示を送るだけ
2. **試合ロジックは純粋なコードにする**：`src/online/` と `src/logic/matchRules.ts` は画面・通信・時間に依存しない。ブラウザでもサーバーでも同じコードが動く
3. **状態は丸ごと送る**：状態が変わるたび、その接続者に見せてよい状態（`OnlineView`）を丸ごと送る。再接続・途中参加（観戦）も「今の状態を1回受け取るだけ」で追いつける
4. **隠すべき情報は送らない**：相手の手札・未公開の選択は、相手にも観戦者にも渡さない（公開されたカードだけが見える）

## ファイル構成（実装済み）

| ファイル | 役割 |
|---|---|
| `src/logic/matchRules.ts` | 5戦→集計→サドンデス突入・再開の進行ルール（NPC対戦・オンライン対戦で共通） |
| `src/online/types.ts` | 席・フェーズ・試合状態（`OnlineMatchState`）・クライアントに渡す状態（`OnlineView`） |
| `src/online/match.ts` | 試合の更新ルール（`onlineReducer`）、視点変換（`viewFor`）、表示名の整形 |
| `src/online/deck.ts` | サーバー側のデッキ検証（IDだけ受け取り、実体はサーバーのカードプールから引く） |
| `src/online/protocol.ts` | クライアント⇔サーバーのメッセージ型と、受信内容の検証（`parseClientMessage`） |
| `src/online/constants.ts` | 制限時間などの設定値（暫定。調整はここだけ） |
| `tests/` | `npm test` で実行する自動テスト |

## 試合の流れ（フェーズ）

```
lobby ──(2人着席)──> deck ──(2人提出)──> pick ──(2人選択確定)──> reveal ──(2人が次へ / 時間経過)─┐
                                          ^                                                      │
                                          └──────────────(まだ続く)───────────────────────────────┤
                                                                                                  v
                                                     finished <──(5戦で決着 / サドンデスで決着 / 不戦敗 / 勝者なし)
```

- 勝敗が確定しても **5戦目まで続ける**（NPC対戦と同じ）
- 5戦で同数なら、同じ5枚に戻してサドンデス。最初に1勝した側が勝ち。1周が全て引き分けならもう一度
- 選択は **確定後に変更できない**（クライアント側で「選ぶ→決定」の2段階にして誤操作を防ぐ）

## 時間と切断（サーバー側のタイマーが、下記のアクションを投入する）

| 状況 | アクション | 暫定値 |
|---|---|---|
| カード選択の時間切れ | `TIMEOUT_PICK`（未選択の席は残りからランダム選択） | 60秒 |
| 結果公開後、確認が揃わない | `TIMEOUT_REVEAL`（自動で次へ） | 8秒 |
| 切断後に戻らない | `FORFEIT { cause: 'disconnect' }`（不戦敗） | 60秒 |
| デッキ未提出 | `FORFEIT { cause: 'deck-timeout' }`（不戦敗） | 180秒 |

## 使えるカード

オンライン対戦は **カードプール全体** から選べる（ストーリーモードの所持カードとは無関係）。
デッキ保存もストーリーモードとは別の保存領域にする（`localStorage` のキーを分ける）。
